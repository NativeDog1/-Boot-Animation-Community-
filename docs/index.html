社区怎么运作

没有服务器、没有账号系统、没有数据库 —— 全靠 GitHub 的免费基础设施。

1 · 投稿是一条 Issue

浏览器先帮你把哈希、分辨率、时长、预览图算好，再打开预填好的 GitHub 表单。机器人校验通过就自动上架。

2 · 数据就是一个 JSON

目录是仓库里的 data/index.json。网站读它，客户端也读它 —— 同一份数据，同一个 id。

3 · 视频由作者托管

我们不转存、不代理、不限速。客户端下载后用 sha256 校验，不符就拒绝安装。
