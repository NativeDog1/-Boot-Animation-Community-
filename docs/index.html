3去 GitHub 提交

点下面的按钮打开投稿表单（名称已帮你预填）。然后在表单里 把同一个视频文件直接拖进「视频」那个文本框 —— GitHub 会自己托管它， 链接会自动填好，你连 sha256 都不用算。

⚠️ 文件超过 25 MB —— GitHub 的 Issue 附件装不下（实测：51 MB 的 4K 视频拖进表单会直接上传失败）。 这种文件必须走 Releases，把直链贴进表单。
但请注意：文件越大，用户下载越容易中途断掉 —— 实测 51.8 MB 的文件在国内只下到 26 MB 就断了。 所以强烈建议压到 30 MB 以内（1440p 通常约 10 MB）。
