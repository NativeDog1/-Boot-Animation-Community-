投稿到社区

填一个 Issue，机器人校验后自动上架

投稿是自助的：填一个 Issue，机器人自动校验，通过就上架。目录不做前置人工审核，采取「自助投稿 + 事后处置」。

  1. 打开 Issues → 新建 →「投稿开机动画」。
  2. 把 mp4 拖进「视频」框。GitHub 会自己上传并把链接填好；也可以直接贴一个 https 直链。名称留空就用文件名，标签可以留空。
  3. 选授权方式、填 nsfw、勾两条声明。nsfw 是必填 —— 漏填会导致条目校验失败，而不是被当成 false。客户端默认隐藏 nsfw: true 的条目，用户可在设置里打开。
  4. 等机器人校验。它会检查必填字段、视频直链是否可达、文件大小与格式，并核对哈希。
  5. 看结果：通过 → 自动生成条目文件、刷新 index.json、合并进目录，并在 Issue 里回复「已上架」；不通过 → 在 Issue 里列出缺哪一项，改好重新提交即可。

视频放哪

最省事
≤ 10 MB 直接把文件拖进表单，链接由 GitHub 生成，你什么都不用管
大文件
贴任何能直接下载的 https 链接即可 —— 自己的 Releases、对象存储、网盘给的临时直链都行。机器人会立刻把它搬进社区仓库托管，所以你的链接不必长期有效
不合格
网盘分享页（要登录、要跳转的那种）。机器人只认直链，不解析网页

预览图是必填字段，但你不用自己准备：机器人会从视频里挑最亮的一帧截出来并提交进仓库。用户下载前看到的就是它。

大文件（4K 原画等）怎么投

GitHub 的 Issue 附件上限是 10 MB，所以按体积分两条路 —— 两条都不需要你有仓库、也不需要建 Release：

  1. ≤ 10 MB

    直接把文件拖进投稿表单的「视频」框。GitHub 会自己托管它、自动把链接填好；其余数字机器人都会自己算。

  2. 大于 10 MB

    把视频传到任何一个能直接下载的地方（自己的 Releases、对象存储、网盘给的临时直链都行），把链接粘进表单的「视频」框。机器人会立刻把视频搬进社区仓库的托管 Release 长期托管，所以你那个链接只要在它下载的那几分钟里有效就够了。

上架后目录里的 video 指向的是社区仓库自己的地址，不会因为你删掉文件、分享过期或网盘限速而失效。你给的原始链接会记在条目的可选字段 source 里便于追溯。

建议 4K 原画之外再单独投一版 1440p（约 10 MB）。 客户端下载支持断点续传（连接中断会自动接着下、不用从头再来），但大文件终究要等一会儿，而多数人只想要一个几秒钟就能装好的片头。两条投稿互不影响，先上 1440p、之后再补 4K 也完全可以。

最省事的一条路：在站点的投稿向导里选好文件，点「切成附件分片」—— 它会用流式哈希算出校验值（多大的文件都不会卡）、把视频切成 20 MB 一块写进你选的文件夹，并把分片信息自动填进投稿表单。你只要把这些分片一起拖进表单即可：不需要仓库、不需要 Release、也不需要网盘。机器人拼回后会核对哈希，顺序错了或漏了分片都会明确告诉你。

硬性要求（机器人会卡）

  • video 和 preview 必须是 https 直链。
  • sha256 必须与文件完全一致 —— 这是唯一的安全校验手段，改了视频就必须改哈希。
  • 体积上限 2 GB（社区托管用的 Release 单文件上限）、时长上限 30 秒；建议 1440p、30 MB 以内 —— 4K 原画贴个直链就行，机器人会替你托管。
  • 投稿即表示你声明拥有该视频的权利或已获得授权，并在条目里写明 license（例如 CC-BY-4.0、CC0-1.0）。

举报与下架

任何人都可以对任何条目提 Issue（选「举报」模板），写明条目 id 与理由。维护者核实后会直接下架（删除条目文件 + 刷新索引），必要时封禁投稿者。内容不得含违法、色情、暴力或仇恨内容。

data/index.json 由机器人从条目文件生成，不要手改；条目格式的任何变更都要保证向后兼容，新字段可选。
