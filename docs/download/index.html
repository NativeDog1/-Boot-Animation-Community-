安装前需要知道

第一次运行会有 SmartScreen 提示。 安装包目前没有代码签名，Windows 会显示「Windows 已保护你的电脑」。点「更多信息 → 仍要运行」即可。这是微软的信任机制，不是检测到了病毒。
它只动三个地方，都不要管理员： 程序目录、一条 HKCU 自启键值、以及一个数据目录（选片与日志，卸载时保留）。不改引导、不改登录外壳、不装驱动。
