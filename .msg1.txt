perf+fix(site): 内容页静态预渲染、路径安全闸门、可访问性修正、补单元测试

把网站按"最终交付物"又过了一遍，改的都是会真出问题的地方。

## 安全

生成器新增**路径安全闸门**：id 与作者名会变成文件路径（`animations/<id>/`、
`creators/<author>/`），而数据来自公开投稿 —— 之前一个 `../../../x` 就能让
生成器往仓库外面写文件。现在非法片段直接跳过并打印警告，绝不拿去拼路径。

## 静态优先（SEO 与禁用 JS 场景）

- 下载页的版本区、事实表、主按钮改为**构建时预渲染**（读 data/software.json）
- 社区页的投稿流程（5 个步骤、为什么用 Issue、内容与下架）改为预渲染
- 库页静态卡片设上限 48 张，其余交给 JS 按需渲染，并用 `<noscript>` 交代清楚

## 正确性

- 修 `download.js` 一个真 bug：取不到远端版本清单时会用「还没有发布安装包」
  **覆盖**掉静态渲染好的「已发布 1.0.0」—— 一次网络抖动就会向用户说假话。
  现在静态里有版本号就不覆盖，只补一句"暂时取不到最新清单"。
- 首页 Hero 从"长得像播放器但点不动"改成**真的播放器**（点了才设 src，
  首屏依旧不下载任何视频）。
- 详情页标题从侧栏提到两栏之上：源码里 h2 出现在 h1 之前，标题层级不合法。

## 可访问性

- `--fg-3` 由 `#6e7686` 提到 `#8a93a5`：原值在页面底色上只有 **4.31:1**，
  低于 WCAG AA 的 4.5:1，而它正是 `.muted` / 卡片元信息在用的颜色
  （现值：底色 6.4:1、卡片 5.9:1、浮层 5.0:1，token 里写明了怎么复算）
- 移动端菜单打开时给主内容与页脚加 `inert`：Tab 不再跑到被遮住的链接上
- 详情页的双栏布局从内联样式收进 `.detail-layout`

## 测试

- 新增 `tools/catalog.test.mjs`（26 个用例，`node:test`，零依赖）：格式化边界值、
  筛选与四种排序、深链参数编解码、投稿准入阈值（100 MB / 30 s / 4K）、
  **目录源按顺序回退而不是竞速**（竞速会让过期的 CDN 缓存赢）、搜索打分
- `npm test` / `npm run check` 已接入；投稿工作流的 run 步骤也加了单测
  （该文件仍受 .github/workflows 忽略影响，等 gh 的 workflow 权限到位后才真正生效）

## 其他

- 新增 `.gitattributes`（仓库内存 LF），消除"整文件都改了"的假 diff
- 投稿机器人校验不通过就不上架这条逻辑保持不变
